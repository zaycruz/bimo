Build one small React app: a focused task list for a single user.

The app should let the user add a task, mark a task complete, and remove a
task. Keep the interface clear at mobile and desktop widths, use accessible
labels and buttons, and include a small empty-state message. Keep the scope to
one app and its local behavior; do not add accounts, network services, or
deployment work.

Acceptance criteria:

- The app starts with an empty-state message.
- Adding a non-empty task displays it in the list.
- A task can be completed and visibly distinguished.
- A task can be removed.
- The project includes a repeatable check for the core interactions.
